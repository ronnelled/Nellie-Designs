# Nellie Designs

Nellie Designs is a full-stack web application for a handmade pipe cleaner bouquet business.

## Technology Stack

- Frontend: React with Vite
- Backend: Node.js and Express
- Database: PostgreSQL
- API Style: REST API

## Pages

1. Home / Landing Page
2. Product Dashboard
3. Management / CRUD Page

## Functional Requirements

- Multi-page routing with React Router
- Product catalog
- Product CRUD
- API connection between frontend and backend
- PostgreSQL database persistence
- Responsive design
- Empty form validation
